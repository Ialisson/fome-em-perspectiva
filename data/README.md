# Dicionário da base

Arquivo: inseguranca_alimentar.csv, em UTF-8 e separado por vírgulas.

| Coluna | Significado |
|---|---|
| period | Ano ou intervalo de referência publicado pela pesquisa. |
| year | Posição numérica para ordenar pontos; 2017–2018 usa 2018. |
| territory_type | Brasil para totais nacionais ou Grande Região para recortes regionais. |
| territory | Brasil, Norte, Nordeste, Centro-Oeste, Sudeste ou Sul. |
| value | Percentual domiciliar em insegurança grave; vazio quando não há estimativa. |
| survey | Levantamento de origem do valor. |
| source | Link para publicação primária do IBGE. |
| notes | Contexto e ressalvas do registro. |

## Regras editoriais

- Não converter percentual de domicílios em número de pessoas.
- Não estimar anos sem coleta oficial da EBIA pelo IBGE.
- Não misturar levantamentos da Rede PENSSAN à linha histórica do IBGE.
- Comparar regiões apenas dentro do mesmo levantamento de 2024.
- Preservar a precisão publicada e a fonte de cada estimativa.
